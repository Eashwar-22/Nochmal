# A1 lesson candidates

Each directory is a retained review package. A candidate can remain here after
its lesson is published; app visibility comes only from
`curriculum/a1_published/publication.json`:

- `lesson-source.json` contains the authored lesson analysis;
- `compiled-lesson.json` contains the exact typed cards consumed by the app;
- `preview.md` is the same card content in a human-readable review format.
- `review.json` is the stored passing rulebook, language, and translation review
  required before the candidate can be published.

The 48 A1 lessons are already published. The blueprint is
`curriculum/a1_blueprint.md`, and the original staged records remain in
`curriculum/a1_staging/` for traceability.

These files are review evidence, not a queue of lessons waiting for release.
Any future replacement of a published A1 lesson needs a fresh review and the
complete release gate in `docs/grammar-breakdown-rulebook.md`.
