# A2 lesson candidates

This folder holds candidate packages for A2 lesson review. Each package has an
authored source, compiled cards, a readable preview, and review evidence. A
candidate can remain here after its lesson is published; the publication list
in `curriculum/a2_published/publication.json` determines app visibility.

A2 lessons 001–012 are already published. The authored records for lessons
013–072 are in `curriculum/a2_course/lessons/`; their candidate packages are
created when those lesson numbers are requested.

Use [the numbered lesson workflow](../../docs/lesson-workflow.md) for current
creation, audit, audio, preview, and release commands.
